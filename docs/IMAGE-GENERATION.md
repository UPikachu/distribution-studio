# 生图服务配置

更新时间：2026-09-09。

## 使用

在「设置与备份 → AI 生图服务」配置火山方舟、阿里云百炼或 MiniMax，选择默认服务，点击「保存生图配置」。阿里云填写 DashScope `/api/v1` 地址，不使用 OpenAI 兼容地址。

在「素材库 → 生成文章配图」选择服务、画面比例并输入描述，每次生成一张。成功图片自动存入素材库，可插入当前主稿或平台稿。支持横版 16:9、方形 1:1、竖版 3:4。当前是文字生图，尚未提供参考图编辑、标题模板叠字和批量生成。

模型 ID 可以按账号已开通的型号修改。请求不会自动切换供应商，也不会自动重试，以免意外重复计费。请求与下载总超时为 180 秒；关闭客户端会中断本地等待，服务端仍可能计费。

## 用户配置

- 本机配置：系统应用数据目录中的 `image-providers.user.json`，与代码仓库分离。
- macOS 当前目录：`~/Library/Application Support/分发工作台/`。
- 密钥使用 Electron `safeStorage` 加密；未具备系统加密能力时拒绝保存密钥。渲染界面仅返回“已配置”状态，不读取原始密钥。
- 设置中 API Key 留空表示保留原值；勾选对应的“清除此服务密钥”后保存才能删除。
- 导出默认不含密钥。勾选“导出包含明文密钥”用于自己的设备迁移；导出的文件需妥善保管。
- 导出文件统一使用 `.user.json` 后缀；仓库 `.gitignore` 排除此后缀及临时文件。仓库内仅保留无密钥的 `image-providers.example.json` 模板。
- 导入会替换服务地址、模型和默认服务；空密钥保留本机已有密钥。
- 系统加密配置不能直接复制到另一台设备；跨设备使用设置中的导出/导入。
- 普通文章备份不包含生图密钥。生成成功的提示词、模型和参数记录保存在 `image-history/`；图片本身会随工作区备份保存，当前独立生成记录不包含在工作区备份中。

## 接口

- 火山方舟：`POST /api/v3/images/generations`。
- 阿里云百炼：`POST /api/v1/services/aigc/multimodal-generation/generation`，使用 Qwen Image 3.0 同步协议。
- MiniMax：`POST /v1/image_generation`。

请求在主进程完成，API 地址限制为对应服务的官方域名与路径；图片下载不携带 API Key。HTTP 错误、HTTP 200 内业务错误、空图片结果、下载失败与超时均不会被标记为成功。

## 模型选择与记忆

素材库增加模型下拉框：火山支持 Seedream 5.0 Lite、4.5、4.0；阿里支持 Qwen Image 3.0 / Pro；MiniMax 支持 image-01 / image-01-live。设置中的自定义模型也会出现在选择器中。平台切换与模型选择立即保存到现有用户配置，不需要生成图片或额外保存。重启恢复最后平台，每个平台分别恢复自己的最后模型；配置导出/导入同时包含这些偏好。新增 Electron 测试覆盖切页、跨平台切换和进程重启后的恢复。

## 价格提示

生图按钮旁显示低调的单张参考价，随平台与模型切换更新。当前人民币参考价：Seedream 5.0 Lite 0.22、4.5 0.25、4.0 0.20；Qwen Image 3.0 0.18、Pro 0.25（北京地域、当前输出尺寸均为 1K 计价档）；MiniMax image-01 / image-01-live 0.025。统一提示“以实际账单为准”，悬停可查看核对日期及口径。自定义未知模型或未核价地域显示“价格待确认”。修改输出尺寸或增加模型时须同步更新 src/image-pricing.ts。
